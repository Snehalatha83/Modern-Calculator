# 🧮 Modern Calculator

A clean, responsive, and modern calculator built using **HTML**, **CSS**, and **JavaScript**. This project features a glassmorphism-inspired user interface with smooth animations and performs basic arithmetic operations.

## ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖ Multiplication
- ➗ Division
- 🔢 Decimal number support
- 🧹 Clear display
- 🎨 Modern glassmorphism UI
- 📱 Responsive design
- ⚡ Lightweight and fast

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/your-username/Modern-Calculator.git
```

### Open the project

Open the folder and launch `index.html` in your browser.

Or use the **Live Server** extension in Visual Studio Code.

---

## 💡 How It Works

1. Click the number buttons to enter values.
2. Select an arithmetic operator (+, −, ×, ÷).
3. Press **=** to calculate the result.
4. Press **C** to clear the display.
